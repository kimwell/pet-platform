# 本地附件存储与失败补偿

冻结日期：2026-10-07，P01-02。本文拥有磁盘安全、生命周期、票据安全与备份；HTTP/字段由 [附件契约](../contracts/ATTACHMENTS.md) 定义。本轮不实现上传。

PostgreSQL 保存元数据，私有本地目录保存字节。服务端生成 UUID 磁盘名及经过识别的白名单扩展名，规划 `<root>/<tenantId>/<前两位>/<uuid>.<ext>`；原始名称仅做显示/下载 Content-Disposition，去除控制字符与目录分隔符。客户端永不获得机器绝对路径，文件目录不挂为公开静态目录。

上传多层检查：字节流上限（请求声明不可作为实际大小）、规范扩展名、声明 MIME、魔数/可解析内容识别一致；可配置 allowlist **只能收窄**。默认图片 JPEG/PNG/WebP 单文件10MiB，PDF20MiB，MP4视频100MiB；拒绝 SVG/HTML/可执行文件/压缩包与伪装类型。内容识别采用本模块有限格式解析/魔数校验，不新增扫描库作为既定依赖；若需病毒/转码能力，新增明确适配并验证。图片解码另限像素/解压资源，MP4/PDF 的识别不宣称无恶意内容，默认 PDF 下载、视频受限播放，不能任意内联活动内容。

路径只由服务端生成标识组成。创建前规范化 root 并验证父目录真实路径在 root 下；使用 NOFOLLOW_LINKS、拒绝路径链符号链接、独占创建临时文件、受限目录/账号权限。仅 normalize/startsWith 不足以防 TOCTOU，目录不可被其他账号写，读取/删除重新校验；P08 用实际文件系统验证符号链接/路径穿越/并发替换。

## 生命周期与补偿

| 状态/阶段 | 正常行为 | 故障恢复 |
| --- | --- | --- |
| UPLOADING（内部） | 先建元数据意图，流写隔离 .part，计算摘要并验证 | 超时意图/残片由清理任务恢复，不返回可访问附件 |
| TEMPORARY | 同文件系统原子 rename 到 UUID 目标，再短事务标记临时可用，24小时到期 | rename 成功 DB 失败形成孤儿；补偿记录/周期对账，隔离后删除 |
| BOUND | 业务检查资源/版本后同 DB 事务绑定一个 resourceType/resourceId | 业务回滚保持临时；不能把文件 rename 与 DB 当原子分布式事务 |
| DELETING | 先事务标记不可访问、撤销票据、写文件删除意图 | I/O失败重试；逻辑上不可访问，保留故障元数据 |
| DELETED | 字节删除后事务记录完成/保留审计墓碑 | 文件已缺失视幂等成功；异常缺失的 BOUND 文件返回不可用并报警 |

一个附件默认只绑定一个业务资源；不能重复绑定给其他 owner。业务解绑/替换走 owner 应用接口，同事务解除关系并标 DELETING；通用删除不绕过业务规则。临时仅上传人+同租户访问，过期立即拒绝；每小时清理，领取租约避免双执行。24小时后可删临时字节，孤儿至少隔离24小时并核对活跃意图后清理；清理边界和恢复日志可观测。

AttachmentAccessPolicy 按 resourceType 注册，返回某主体对某资源的 READ/BIND/UNBIND/DELETE 是否允许及 Tenant/Store/SELF 归属。未注册、策略错误、无上下文默认拒绝；不能通过传来的 resourceId 自授访问，业务模块拥有策略。

## 下载与短期票据

认证下载按业务策略复核；Content-Type 采用识别值，Content-Disposition 安全编码，nosniff、Cache-Control:private,no-store。默认 attachment 下载，不允许客户端任意切换 inline；合法媒体预览由用途及 allowlist 决定。支持受限单区间 Range，非法范围416；认证及范围检查先于输出，不能把 JSON 错误当二进制成功。

无法附 Header 的小程序 video 使用**服务端随机 opaque 票据**，不是会话 Token/JWT：至少256 bit，库/Redis只存摘要，绑定附件/tenant/主体/session/securityVersion/用途/到期。图片默认认证 downloadFile 到临时路径。下载票据单次使用；媒体票据允许有效期内多次 Range 请求，最多5分钟。每次兑付仍验证账号/session/资源当前权限，过期/停用/解除绑定/撤销均拒绝，不能只验证签名和时间。

票据 URL 同源专用 `/api/integrations/attachments/access/{ticket}`，不接受任何其他认证空间作为兜底；用途受限、HTTPS、无重定向、不可在日志/审计/分析中记录完整 URL，票据视秘密、Referrer-Policy:no-referrer。不能放平台/员工/客户长期 Token 到 query。播放已传输字节无法撤回，授权撤销只控制新请求；浏览器/微信临时文件可能在设备留存，退出时删除，不能声称远程销毁。

## 备份和部署条件

本地存储默认单实例或同一受控共享卷，扩实例前必须验证一致文件访问，不能仅增加后端副本。备份同时包含 PostgreSQL、私有文件目录和可恢复的元数据版本；维护窗口暂停新上传/绑定/删除，或建立一致快照屏障并记录水位。恢复后对账 BOUND 文件/摘要、隔离孤儿，验证跨租户拒绝；不能只恢复数据库便宣布附件可用。
